# Bluejay App Template

This project was created with [the Bluejay App template](https://github.com/apacheli/bluejay-app) and [`$ bun create`](https://bun.sh/docs/cli/bun-create).

## Getting Started

### `bun run serve`

Serves files locally for development. Your server will automatically update whenever file changes occur.

### `bun run build`

Builds files for distribution. You can serve them with GitHub Pages.
