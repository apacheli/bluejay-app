# bluejay App Template

This project was created with [the bluejay App template](https://github.com/apacheli/bluejay-app) and [`bun create`](https://bun.com/docs/runtime/templating/create).

## Getting Started

### `bun clean`

Deletes the `dist` folder.

### `bun dle` (or `bun run build`)

Builds files for distribution. You can serve them with GitHub Pages.

### `bun serve` (or `bun dev`)

Serves files locally for development. Your server will automatically update whenever file changes occur.

### `bun serve:production`

Serve files for "production." For real production purposes, use `bun dle`.
